Changes by Narayan Lekhi: the existing analysis selected 2021–2025 major/main-draw
charts, applied its documented completion and whole-point notation exclusions,
counted exclusive point endings and overlapping stage reaches, calculated
serving/receiving point-win percentages, reconciled pre-point break-point scores,
and classified explicitly recorded ending types and final-action players.
Counts are pooled before division. This website packaging splits already frozen
aggregate player/view records for selective loading and applies approved plain
wording aliases. It also displays wins divided by wins plus losses for points ending at each stage,
using existing counts. No raw point/action records or new scientific analysis
are distributed.
Analysis repository: https://github.com/nanu731/tennis-analytics
